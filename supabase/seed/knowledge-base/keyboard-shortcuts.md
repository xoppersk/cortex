# Keyboard Shortcuts

Cortex is fully keyboard-operable. The core chat flow meets WCAG 2.2 AA: every action below works without a mouse, with visible focus and screen-reader announcements for streaming regions.

## Global

- **Cmd/Ctrl + K** — command palette: new chat, search conversations, jump to a template, go to any page, toggle theme.
- **Cmd/Ctrl + Enter** — send the current message (works from the composer).
- **Esc** — close dialogs, the palette, and the Sources panel; stops a streaming response when the composer is focused.

## Chat

- **N** (from the palette) — new chat.
- **/** — focus conversation search in the sidebar.
- **R** — regenerate the last assistant response.
- **S** — stop the current stream.

## Navigation

- **G then H** — history. **G then T** — templates. **G then U** — usage. **G then K** — knowledge bases.
- **?** — open this shortcut reference.

## Composer

The composer auto-grows as you type and shows a live token estimate. **Shift+Enter** inserts a newline. Attachments: **Cmd/Ctrl+U** opens the file picker (PDF, TXT, MD, CSV up to 10 MB per message).
